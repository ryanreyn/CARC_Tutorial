# CARC_Tutorial
This repository is designed to demonstrate how to use the USC CARC remote computing resources and to offer tools and tutorials for CARC users to take advantage of. **Jupyter notebook** tutorials are provided in the *tutorials* folder, while the individual files created manually in these tutorials are hosted in the *tools* folder and can be used as templates for a user's own job submission needs. More documentation on the contents of this repository including how to use git and the typical CARC job architecture/pipeline can be found on the associated [wiki](https://github.com/ryanreyn/CARC_Tutorial/wiki).

## Installing this repository directly
This repository is actively being developed, but a package release is coming for those who would like to directly install the scripts in this repo. Currently interested users can access the tools and tutorials by cloning the repository directly into their CARC project folder using the following command:
```
git clone https://github.com/ryanreyn/CARC_Tutorial.git <your-local-directory>
```
where `<your-local-directory>` is the optional name you can give for the folder to clone the repository into. If no directory is specified, it will be cloned into your current directory instead. For more information on how to setup and use git on CARC, visit the **Using git on CARC** [wiki page](https://github.com/ryanreyn/CARC_Tutorial/wiki/Using-git-on-CARC).

## Jupyter Notebooks with CARC OnDemand
For greater accessibility, the individual scripts provided in the *tools* directory have also been combined into a dynamic **Jupyter Notebook** file that users can run dynamically. CARC offers a convenient web-based GUI that allows users to access, run, and modify **Jupyter Notebook** files stored on the remote system. To access this GUI you can visit the [CARC OnDemand](https://ondemand.carc.usc.edu) website and login using your USC credentials and launch a **JupyterLab** interactive session. Similarly to a job submitted with SLURM, you will need to provide the specific account and partition information that tells the CARC system what resources you are authorized to access. Refer to the **Running jobs on CARC** [wiki page](https://github.com/ryanreyn/CARC_Tutorial/wiki/Running-jobs-on-CARC) for more information on what these specifications are.
